## Tech Portal Mobile Issues

The Tech Portal is designed for mobile phones, but you might encounter these issues:

### Screen doesn't fit properly

Solutions:
1. Rotate your phone (try both portrait and landscape)
2. Clear your browser cache
3. Use a different browser (Chrome or Safari recommended)
4. Make sure you're at the `/tech-portal` URL, not the dashboard

### Buttons not responding

Solutions:
1. Wait for the page to fully load
2. Check your internet connection
3. Refresh the page
4. Close other browser tabs

### Camera not working for photos

Solutions:
1. Allow camera permissions when prompted
2. Go to phone Settings > Browser > Camera Permissions
3. Clear the browser and try again
4. Restart your phone

### Page loads slowly

Solutions:
1. Connect to Wi-Fi instead of cellular
2. Close other apps running in background
3. Clear browser cache
4. Update your browser to the latest version

## Owner Dashboard on Mobile

The Owner Dashboard is optimized for desktop but works on tablets:

### Kanban board hard to use

Recommendation: Use a tablet or desktop for the full dashboard. The Kanban drag-and-drop works best with larger screens.

### Can't see all metrics

Solution: Scroll horizontally or use landscape mode on tablets.

## General Mobile Tips

1. Bookmark the page for quick access
2. Add to Home Screen for app-like experience
3. Keep browser updated for best performance
4. Use stable internet for real-time features
